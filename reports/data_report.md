# Data report

Generated by `scripts/prepare_data.py`. Source: Kromp et al. 2023, *An annotated human blastocyst dataset to benchmark deep learning architectures for in vitro fertilization*, Scientific Data (CC BY 4.0).

## What's in the dataset

| item | count |
|---|---|
| images (512x384 microscope photos, day 4-5 blastocysts) | 2344 |
| patient IDs | 851 |
| silver-labelled images (one expert) | 2042 |
| gold-labelled images (multi-expert consensus test set) | 300 |
| images with conflicting silver labels | 1 |
| unlabelled images | 1 |
| transferred embryos with clinical data + outcomes | 754 |
| patients with outcomes | 732 |

The paper reports 837 patients and 752 transferred embryos; the files contain 851 patient IDs and 754 transferred embryos.

## Data cleaning

| problem | rows |
|---|---|
| AMH stored as a date, 'Mon.YY' form (e.g. Jän.26 = 1.26) | 377 |
| AMH stored as a date, 'DD.Mon' form (e.g. 02.Nov = 2.11) | 124 |
| ...of which ambiguous (01.Apr = 1.4 or 1.04; midpoint used) | 118 |
| AMH missing | 165 |
| endometrium stored as a date (08.Mai = 8.5 mm) | 144 |
| endometrium missing | 12 |
| egg counts written as sums (10+1) | 9 |
| egg retrieval count (COC) missing | 5 |

Image names are matched on (patient, embryo) numbers because padding is inconsistent (`187_1.png` in a CSV, `187_01.png` on disk). The undocumented `Fond` column is dropped.

## Outcomes (transferred embryos)

| outcome | positive | negative | rate |
|---|---|---|---|
| positive pregnancy test (SS) | 317 | 437 | 0.420 |
| ongoing pregnancy with heartbeat (HA) | 261 | 493 | 0.346 |
| live birth (LB) | 234 | 520 | 0.310 |

Rows where outcomes are out of order (live birth without heartbeat, etc.): 1.

Double embryo transfers: 22 patients had two embryos transferred together. Both embryos get the transfer's outcome, so for these we can't tell which embryo implanted (a known source of label noise in IVF data).

**Main target: live birth (LB).** It's the outcome patients care about, and has 234 positives.
