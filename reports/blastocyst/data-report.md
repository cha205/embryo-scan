# Data report

This report is generated by `scripts/blastocyst/prepare_data.py`. The source is Kromp et al. (2023), *An annotated human blastocyst dataset to benchmark deep learning architectures for in vitro fertilization*, Scientific Data (CC BY 4.0).

## Dataset contents

| item | count |
|---|---|
| images (512 x 384 microscope images of day-4 and day-5 blastocysts) | 2344 |
| patient identifiers | 851 |
| silver-labelled images (single embryologist) | 2042 |
| gold-labelled images (consensus test set of an expert panel) | 300 |
| images with conflicting silver labels | 1 |
| unlabelled images | 1 |
| transferred embryos with clinical data and outcomes | 754 |
| patients with outcomes | 732 |

The original publication reports 837 patients and 752 transferred embryos, whereas the released files contain 851 patient identifiers and 754 transferred embryos.

## Data cleaning

| defect | rows |
|---|---|
| AMH stored as a date, 'Mon.YY' form (e.g. Jän.26 = 1.26) | 377 |
| AMH stored as a date, 'DD.Mon' form (e.g. 02.Nov = 2.11) | 124 |
| ...of which ambiguous (01.Apr = 1.4 or 1.04; midpoint used) | 118 |
| AMH missing | 165 |
| endometrial thickness stored as a date (08.Mai = 8.5 mm) | 144 |
| endometrial thickness missing | 12 |
| oocyte counts written as sums (10+1) | 9 |
| number of cumulus-oocyte complexes (COC) missing | 5 |

Image names are matched on (patient, embryo) numbers because their zero-padding is inconsistent (`187_1.png` in a CSV file and `187_01.png` on disk). The undocumented `Fond` column is discarded.

## Outcomes (transferred embryos)

| outcome | positive | negative | rate |
|---|---|---|---|
| positive pregnancy test (SS) | 317 | 437 | 0.420 |
| ongoing pregnancy with fetal heartbeat (HA) | 261 | 493 | 0.346 |
| live birth (LB) | 234 | 520 | 0.310 |

Number of rows with inconsistent outcomes (for example, a live birth without a heartbeat): 1.

In 22 patients, two embryos were transferred together. Both embryos inherit the outcome of the transfer, so it cannot be determined which embryo implanted; this is a known source of label noise in IVF data.

**Primary outcome: live birth (LB).** Live birth is the outcome of greatest clinical relevance, and 234 transferred embryos resulted in a live birth.
